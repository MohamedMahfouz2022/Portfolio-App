## 📖 About

A fully responsive, professionally designed developer portfolio showcasing frontend projects, technical skills, and client work. Built with the latest Next.js 14 App Router for optimal performance, SEO, and developer experience.

---

## ✨ Features

- ⚡ **Next.js 14 App Router** — server components, streaming, and nested layouts
- 🎨 **shadcn/ui** — accessible, customizable component library
- 💨 **Tailwind CSS** — utility-first styling with a consistent design system
- 🤖 **GitHub Actions CI/CD** — automated build checks on every push
- 📱 **Fully Responsive** — optimized for mobile, tablet, and desktop
- 🌐 **Vercel Deployment** — production-grade hosting with preview deployments
- ♿ **Accessible** — semantic HTML and ARIA compliance

## 📁 Folder Structure

## 🚀 Installation

```bash
# 1. Clone the repository
git clone https://github.com/MohamedMahfouz2022/Portfolio-App.git
cd Portfolio-App

# 2. Install dependencies
npm install

# 3. Run development server
npm run dev

# 4. Open in browser
# http://localhost:3000
```
